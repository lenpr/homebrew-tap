# Homebrew Tap

Custom Homebrew tap for [PDFwringer](https://github.com/lenpr/PDFwringer) and other tools.

## Installation

```bash
brew tap lenpr/tap
brew install --cask pdfwringer
```

## Available Casks

| Cask | Description |
|------|-------------|
| `pdfwringer` | Lightweight PDF compression, merging, splitting, rotating, cropping, and editing |

## Updating

```bash
brew update
brew upgrade --cask pdfwringer
```
